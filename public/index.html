🚃 TrainOS

ブラウザの中で動く、超細分化 WebOS。電車が好きなので TrainOS。

  • ファイルがそのまま OS: Google Drive かローカルのフォルダに sys/ と usr/ を置くだけ。
  • ネジ1本からハック: sys/components/ や sys/boot_loader/ に JS を置くと、挙動や起動画面を差し替えられる。
  • アプリは置くだけ: sys/apps/ に HTML を入れたら使える。各アプリは iframe で隔離される。
  • 壊れても戻れる: URL に ?mode=safe を付けると、カスタムコードを無視して起動する。
